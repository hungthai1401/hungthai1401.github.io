Trước khi bắt đầu
Nếu dự án Laravel của bạn chưa tồn tại: laravel new booking-app rồi cd booking-app. Laravel 11+ mặc định dùng Pest cho test - các ví dụ dưới dùng cú pháp Pest.

Bước 1 - Value Objects

app/Domain/Scheduling/ValueObjects/TimeSlot.php

declare(strict_types=1);

namespace App\Domain\Scheduling\ValueObjects;

use DateTimeImmutable;
use InvalidArgumentException;

final class TimeSlot
{
    public function __construct(
        public readonly DateTimeImmutable $start,
        public readonly DateTimeImmutable $end,
    ) {
        if ($start >= $end) {
            throw new InvalidArgumentException(
                'Thời gian bắt đầu phải trước thời gian kết thúc'
            );
        }
    }

    public function overlaps(self $other): bool
    {
        return $this->start < $other->end && $other->start < $this->end;
    }

    public function equals(self $other): bool
    {
        return $this->start == $other->start && $this->end == $other->end;
    }
}

app/Domain/Scheduling/ValueObjects/RoomId.php và BookingId.php (cùng khuôn mẫu):

final class RoomId
{
    private function __construct(public readonly string $value) {}

    public static function from(string $value): self
    {
        return new self($value);
    }

    public function equals(self $other): bool
    {
        return $this->value === $other->value;
    }
}

final class BookingId
{
    private function __construct(public readonly string $value) {}

    public static function generate(): self
    {
        return new self(bin2hex(random_bytes(16)));
    }

    public static function from(string $value): self
    {
        return new self($value);
    }
}
Chú ý
Không dùng Illuminate\Support\Str::uuid() ở đây - dù tiện, nó vẫn là import từ Laravel. Domain layer (bài 6) nên chỉ phụ thuộc PHP thuần. random_bytes() là hàm PHP core, không phải Laravel.

final class Booking
{
    private BookingStatus $status;

    public function __construct(
        private readonly BookingId $id,
        private readonly TimeSlot $timeSlot,
    ) {
        $this->status = BookingStatus::Held;
    }

    public function confirm(): void { $this->status = BookingStatus::Confirmed; }
    public function cancel(): void { $this->status = BookingStatus::Cancelled; }

    public function id(): BookingId { return $this->id; }
    public function timeSlot(): TimeSlot { return $this->timeSlot; }
    public function status(): BookingStatus { return $this->status; }
}

Bước 3 - Aggregate Root: RoomSchedule

app/Domain/Scheduling/Models/RoomSchedule.php

final class RoomSchedule
{
    /** @var Booking[] */
    private array $bookings = [];

    private function __construct(private readonly RoomId $roomId) {}

    public static function empty(RoomId $roomId): self
    {
        return new self($roomId);
    }

    public function roomId(): RoomId { return $this->roomId; }

    /** @return Booking[] */
    public function bookings(): array { return $this->bookings; }

    public function reserve(TimeSlot $slot): Booking
    {
        foreach ($this->bookings as $existing) {
            if ($existing->status() !== BookingStatus::Cancelled
                && $existing->timeSlot()->overlaps($slot)) {
                throw new SlotAlreadyBooked(
                    'Khung giờ này đã có người đặt cho phòng này'
                );
            }
        }

        $booking = new Booking(BookingId::generate(), $slot);
        $this->bookings[] = $booking;

        return $booking;
    }
}
Đây chính là bài 3, viết thành code thật
Invariant "không trùng khung giờ" nằm hoàn toàn trong reserve(). Chú ý điều kiện bỏ qua booking đã Cancelled - một booking bị hủy không còn "chiếm" khung giờ nữa, cho phép người khác đặt lại đúng giờ đó.

Bước 4 - Test: chạy được không cần DB, không cần Laravel

tests/Unit/Domain/Scheduling/RoomScheduleTest.php

use App\Domain\Scheduling\Exceptions\SlotAlreadyBooked;
use App\Domain\Scheduling\Models\BookingStatus;
use App\Domain\Scheduling\Models\RoomSchedule;
use App\Domain\Scheduling\ValueObjects\RoomId;
use App\Domain\Scheduling\ValueObjects\TimeSlot;

function slot(string $start, string $end): TimeSlot
{
    return new TimeSlot(new DateTimeImmutable($start), new DateTimeImmutable($end));
}

it('cho phép đặt một khung giờ trống', function () {
    $schedule = RoomSchedule::empty(RoomId::from('room-1'));

    $booking = $schedule->reserve(slot('09:00', '10:00'));

    expect($booking->status())->toBe(BookingStatus::Held);
    expect($schedule->bookings())->toHaveCount(1);
});

it('không cho phép đặt trùng khung giờ', function () {
    $schedule = RoomSchedule::empty(RoomId::from('room-1'));
    $schedule->reserve(slot('09:00', '10:00'));

    expect(fn () => $schedule->reserve(slot('09:30', '10:30')))
        ->toThrow(SlotAlreadyBooked::class);
});

it('cho phép đặt lại đúng giờ của một booking đã bị hủy', function () {
    $schedule = RoomSchedule::empty(RoomId::from('room-1'));
    $first = $schedule->reserve(slot('09:00', '10:00'));
    $first->cancel();

    $second = $schedule->reserve(slot('09:00', '10:00'));

    expect($second->status())->toBe(BookingStatus::Held);
});
./vendor/bin/pest tests/Unit/Domain/Scheduling/RoomScheduleTest.php
Vì sao test này chạy nhanh và không cần RefreshDatabase?
Không có Eloquent, không có Illuminate\Foundation\Testing nào được dùng. RoomSchedule là PHP thuần - test này chỉ là PHPUnit/Pest thực thi trực tiếp, không boot Laravel, không kết nối DB. Đây chính là lợi ích cụ thể của việc giữ Domain layer sạch (bài 6).

Bước 5 - Repository + Eloquent (khi cần persist)

Interface ở Domain (đã viết ở bài 6, RoomScheduleRepository) giữ nguyên. Phần Eloquent - migration, Model, và cách map qua lại - để bài sau khi bạn thật sự cần lưu dữ liệu (persist), tránh làm bài này quá dài. Cho tới lúc đó, RoomSchedule đã hoàn chỉnh và test được độc lập - đủ để bạn tự tin logic nghiệp vụ cốt lõi đúng, trước khi đụng vào database.

Checklist copy vào dự án của bạn

  1. mkdir -p app/Domain/Scheduling/{Models,ValueObjects,Exceptions}
  2. Copy 6 file ở Bước 1-3 vào đúng namespace App\Domain\Scheduling\...
  3. Copy file test ở Bước 4 vào tests/Unit/Domain/Scheduling/
  4. Chạy ./vendor/bin/pest - phải thấy 3 test pass, không cần config database
  5. Quay lại đây báo kết quả - nếu test đỏ, mình debug cùng bạn

Vướng ở đâu? Lỗi namespace, autoload PSR-4, hay Pest chưa cài (composer require pestphp/pest --dev --with-all-dependencies) đều là chuyện thường - báo mình lỗi cụ thể, đừng tự loay hoay quá lâu.
