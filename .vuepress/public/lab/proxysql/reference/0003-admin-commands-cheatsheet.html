ProxySQL Admin interface — bảng và lệnh cốt lõi

Kết nối Admin interface

mysql -u admin -padmin -h 127.0.0.1 -P 6032 --prompt 'ProxySQL Admin> '

Đây là một MySQL server "giả" — bạn dùng SQL để đọc/sửa config, không phải config file.

3 lớp config — nhớ thứ tự này

LớpÝ nghĩaLệnh chuyển sang lớp kế
Bảng chính (ví dụ mysql_servers)Bộ nhớ tạm, bạn sửa ở đây trướcLOAD ... TO RUNTIME
runtime_* (ví dụ runtime_mysql_servers)Config đang thực sự chạySAVE ... TO DISK
disk.* (SQLite)Config persist, sống sót qua restart—

Quy tắc sống cònSửa bảng chính mà quên LOAD ... TO RUNTIME → không có gì đổi thật. Load runtime mà quên SAVE ... TO DISK → restart process là mất hết, phải làm lại.

Setup lần đầu — trình tự chuẩn

-- 1. Thêm backend server vào hostgroup
INSERT INTO mysql_servers(hostgroup_id,hostname,port) VALUES (1,'10.0.0.1',3306); -- writer
INSERT INTO mysql_servers(hostgroup_id,hostname,port) VALUES (2,'10.0.0.2',3306); -- reader

-- 2. Cấu hình monitor user (phải tồn tại thật trên MySQL, có quyền REPLICATION CLIENT)
UPDATE global_variables SET variable_value='monitor' WHERE variable_name='mysql-monitor_username';
UPDATE global_variables SET variable_value='monitor' WHERE variable_name='mysql-monitor_password';
LOAD MYSQL VARIABLES TO RUNTIME;
SAVE MYSQL VARIABLES TO DISK;

-- 3. Khai báo hostgroup nào là writer/reader theo read_only (Async Replication)
INSERT INTO mysql_replication_hostgroups (writer_hostgroup,reader_hostgroup,comment)
  VALUES (1,2,'cluster1');

-- 4. Load server + xác nhận monitor hoạt động
LOAD MYSQL SERVERS TO RUNTIME;
SELECT * FROM monitor.mysql_server_read_only_log ORDER BY time_start_us DESC LIMIT 5;

-- 5. Thêm user cho application
INSERT INTO mysql_users(username,password,default_hostgroup) VALUES ('appuser','apppass',1);
LOAD MYSQL USERS TO RUNTIME;
SAVE MYSQL USERS TO DISK;

-- 6. Query rule: route SELECT sang reader hostgroup (2), còn lại theo default_hostgroup (1)
INSERT INTO mysql_query_rules (rule_id,active,match_digest,destination_hostgroup,apply)
  VALUES (1,1,'^SELECT.*FOR UPDATE$',1,1);   -- SELECT...FOR UPDATE vẫn phải ra writer
INSERT INTO mysql_query_rules (rule_id,active,match_digest,destination_hostgroup,apply)
  VALUES (2,1,'^SELECT',2,1);                -- SELECT thường ra reader
LOAD MYSQL QUERY RULES TO RUNTIME;
SAVE MYSQL QUERY RULES TO DISK;

-- 7. Lưu toàn bộ server config xuống disk
SAVE MYSQL SERVERS TO DISK;

Bẫy thường gặpQuery rules được đánh giá theo rule_id tăng dần, và apply=1 nghĩa là dừng luôn, không xét rule tiếp theo. Rule nào cần ưu tiên (như chặn SELECT...FOR UPDATE ra writer) phải có rule_id nhỏ hơn.

Bảng cần nhớ

BảngDùng cho
mysql_serversBackend server + hostgroup nào
mysql_replication_hostgroupsAsync/Semisync — map writer/reader hostgroup theo read_only
mysql_group_replication_hostgroupsGroup Replication — xem Reference 0002
mysql_galera_hostgroupsGalera/PXC — xem Reference 0002
mysql_usersUser application, default_hostgroup route mặc định
mysql_query_rulesRoute theo nội dung query, rewrite, cache, block
global_variablesToàn bộ config runtime (monitor user, timeout, listen port...)

Kiểm tra sức khoẻ nhanh

SELECT * FROM stats_mysql_connection_pool;         -- connection/traffic theo hostgroup
SELECT * FROM stats_mysql_query_digest LIMIT 10;    -- query nào chạy, hostgroup nào nhận
SELECT * FROM monitor.mysql_server_ping_log
  ORDER BY time_start_us DESC LIMIT 5;              -- backend còn sống không
