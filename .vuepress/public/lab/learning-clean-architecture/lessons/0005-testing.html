Testing

Bài 5 / Clean Architecture + Laravel · ~10 phút

Bốn bài trước đã nhắc liên tục: "test không cần database". Bài này biến lời hứa đó thành code thật — và chỉ ra rằng Clean Architecture không loại bỏ test có database, nó chỉ giảm số lượng test cần đến database xuống mức tối thiểu.

Ba tầng test, khớp với ba tầng architecture

TầngTest gìCần gìTốc độ
Entity test Business rule thuần (Order::cancel()) Không gì cả — chỉ PHPUnit <1ms / test
Use Case test Flow điều phối, gọi Port đúng thứ tự Fake implementation của Port ~1-5ms / test
Adapter test Mapping Entity ↔ Eloquent đúng, SQL đúng Database thật (SQLite in-memory được) ~10-50ms / test
Nguyên tắc: đảo ngược test pyramid truyền thống

Trong app viết theo layered thông thường, hầu hết test phải chạm database vì business logic dính trong Eloquent. Với Clean Architecture, đa số test (Entity + Use Case) không cần database — chỉ một lớp mỏng (Adapter test) mới cần.

Tầng 1: Entity test — không mock gì cả

// tests/Unit/Domain/OrderTest.php
class OrderTest extends TestCase {
    public function test_cannot_cancel_shipped_order(): void {
        $order = OrderFactory::shipped();  // factory dựng Entity trong RAM

        $this->expectException(CannotCancelShippedOrder::class);
        $order->cancel(new DateTimeImmutable());
    }

    public function test_cannot_cancel_after_24_hours(): void {
        $createdAt = new DateTimeImmutable('-25 hours');
        $order = OrderFactory::pendingCreatedAt($createdAt);

        $this->expectException(CancellationWindowExpired::class);
        $order->cancel(new DateTimeImmutable());
    }
}

Không RefreshDatabase, không artisan migrate, không HTTP. new Order(...) rồi gọi method. Đây là lý do tách Entity khỏi Eloquent (Bài 2) đáng công.

Tầng 2: Use Case test — Fake thay cho Mock

Đây là chỗ nhiều người dùng Mockery::mock() hoặc $this->createMock(). Nó hoạt động, nhưng có xu hướng làm test giòn (fragile) — test biết quá nhiều về cách Use Case gọi Port, không chỉ kết quả. Một Fake — implementation thật, chạy trong RAM — thường bền hơn.

// tests/Fakes/InMemoryOrderRepository.php
final class InMemoryOrderRepository implements OrderRepository {
    private array $orders = [];

    public function save(Order $order): void {
        $this->orders[$order->id()->value()] = $order;
    }

    public function find(OrderId $id): Order {
        return $this->orders[$id->value()] ?? throw new OrderNotFound();
    }
}
// tests/Unit/Application/CreateOrderUseCaseTest.php
class CreateOrderUseCaseTest extends TestCase {
    public function test_creates_order_when_payment_succeeds(): void {
        $orders = new InMemoryOrderRepository();
        $payment = new FakePaymentGateway(alwaysSucceeds: true);
        $useCase = new CreateOrderUseCase($orders, $payment);

        $output = $useCase->execute(new CreateOrderInput('cust-1', [['sku' => 'A', 'qty' => 2]]));

        $this->assertSame('pending', $output->status);
        $this->assertNotNull($orders->find(OrderId::fromString($output->orderId)));
    }

    public function test_throws_when_payment_fails(): void {
        $useCase = new CreateOrderUseCase(
            new InMemoryOrderRepository(),
            new FakePaymentGateway(alwaysSucceeds: false),
        );

        $this->expectException(PaymentFailedException::class);
        $useCase->execute(new CreateOrderInput('cust-1', [['sku' => 'A', 'qty' => 1]]));
    }
}
Fake vs Mock — khi nào dùng cái nào?

Fake (implementation thật, đơn giản): dùng cho Port bạn gọi nhiều lần, muốn test hành vi thật (lưu rồi đọc lại). Mock (kiểm tra lệnh gọi): dùng khi bạn chỉ cần assert "method X có được gọi với tham số Y" — ví dụ verify NotificationGateway::send() được gọi đúng một lần.

Tầng 3: Adapter test — database thật, nhưng ít

Fake không tự động đúng. Bạn vẫn cần một test xác nhận EloquentOrderRepository thật sự lưu và đọc đúng dữ liệu — mapping Entity ↔ Eloquent (Bài 2) có thể sai. Đây là chỗ database thật (hoặc SQLite in-memory cho tốc độ) xuất hiện — nhưng chỉ ở tầng Adapter, không lan lên Use Case hay Entity.

// tests/Integration/EloquentOrderRepositoryTest.php
class EloquentOrderRepositoryTest extends TestCase {
    use RefreshDatabase;  // duy nhất chỗ này cần DB

    public function test_save_then_find_returns_equivalent_order(): void {
        $repo = new EloquentOrderRepository();
        $order = OrderFactory::pending();

        $repo->save($order);
        $found = $repo->find($order->id());

        $this->assertTrue($order->equals($found));
    }
}
